# v2 insights (Ronith, 2026-10-11)

Ronith's notes after reviewing similar tools and HCI research, kept verbatim as the source for D21–D23 and DESIGN v2. Claude's reading of each one is in the right column of DESIGN.md §0.

> - Implication: while the marginalia / notes should be centered in the text, it could be helpful to have a separate viewer / minimized window that the user can select to see the pdf of the actual text if they want, or when a user clicks on the source
> - Implication: the AI should read the notes from the user and the page numbers offered to create the linkages directly, the page numbers may be slightly off and they should be grounded in the actual text that was selected / added to the notes rather than concretely being selected against the page number
> - MVP: at the start, the viewer can be linked directly to the page number that the user provides, future iteration should have it use a combination of regex + AI around the selected pages to make the linkage
> - there should be a folder organization system at the top level
> - Idea: Create something similar for Tertulia where we have folders that are organized by books. Each folder contains a book / pdf and then the main notes that exists for the user to engage through integrated AI margin notes
> - I like how there is the ability to select different views from the top. For Tertulia, this could be the following:
>   (1) Notes + integrated AI margins
>   (2) Notes only
>   (3) PDF book only
>   (4) Chat only
>
>   For the user interface it can be divided in the following way: 1/6 is sidebar that can be opened and closed with button. Then 3/6 is the notes. The remaining 2/6 can then be the AI margin notes, the pdf book, or the chat based on what has been selected / opened
> - create a simple pdf upload or url link option for us to upload in the core text
