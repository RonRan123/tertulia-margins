# tertulia-margins

*A tertulia of one.* A note-first AI reading partner for books: you write the margin notes, it talks back.

Paste a passage and write your notes the way you already do. Then ask questions or run `/define`, `/quiz`, or `/expand` on a line. The AI answers from the text, cites the paragraph, and says "not in the text" when the text doesn't support an answer. Notes export to markdown for Obsidian.

**Status:** design phase. See [docs/DESIGN.md](docs/DESIGN.md).
